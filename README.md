# Holberton School - Machine Learning

This repository contains projects completed as part of the Holberton
School Machine Learning specialization, covering topics such as
supervised learning, unsupervised learning, and reinforcement learning.

## supervised_learning/cnn

This directory covers Convolutional Neural Networks (CNNs), including:

* Forward propagation over convolutional and pooling layers
* Back propagation over convolutional and pooling layers
* Building CNNs with Keras and TensorFlow

### Files

* `0-conv_forward.py` - Performs forward propagation over a
  convolutional layer of a neural network.
