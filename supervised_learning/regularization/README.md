# Regularization

This project covers regularization techniques used to prevent overfitting in neural networks, including L1 and L2 regularization, dropout, early stopping, and data augmentation.

## Learning Objectives

By the end of this project, you should be able to explain:

* What is regularization? What is its purpose?
* What is are L1 and L2 regularization? What is the difference between the two methods?
* What is dropout?
* What is early stopping?
* What is data augmentation?
* How do you implement the above regularization methods in Numpy? In Tensorflow?
* What are the pros and cons of the above regularization methods?

## Requirements

* Ubuntu 20.04 LTS
* Python 3.9
* numpy 1.25.2
* tensorflow 2.15
* pycodestyle 2.11
